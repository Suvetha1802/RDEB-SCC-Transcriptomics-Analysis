This directory documents the datasets used in the RDEB–SCC transcriptomics project.

| Group | Number of samples |
|---|---:|
| Healthy | 16 |
| RDEB | 10 |
| SCC | 8 |
| Total | 34 |

## Planned Comparisons

- RDEB vs SCC
- SCC vs Healthy
- RDEB vs Healthy

## Data Types

- RNA-seq sequencing reads or gene-level count data
- Sample metadata and group assignments
- Variant call data and annotation results, where available

## Data Management

Raw data are not stored in this repository by default. Record the original public dataset accession, source URL, reference genome, annotation version, and download date when available.

Before analysis, verify sample identifiers, group labels, file integrity, and data-sharing permissions.

Do not commit private, restricted, or personally identifiable information.
